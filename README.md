# 지원서에서 실제 2년으로

**홍익대학교 일반대학원 세종캠퍼스 국방AI융합학과의 2027~2029년 학업·연구 실현 가능성을 검토한 개인 연구보고서.**

기존의 '면접 연습 웹앱' 컨셉은 사용자 의도와 달라 2026-10-31 전면 폐기했어. 현재 `index.html`은 **읽기 중심의 심층 보고서**야. 면접 답변은 학교·학업·연구·근무 병행을 따져 본 뒤 마지막 장에서 정리하는 결론으로만 배치했어.

## 읽는 법

1. `index.html`을 내려받아 크롬/웨일에서 열어. 인터넷이나 서버 없이 작동해.
2. 왼쪽 목차로 이동하며 실제 대학원 생활을 어떻게 할지 읽어.
3. 원문이 필요하면 문서 끝 **부록 A**(수학계획서 원문)와 **부록 B**(기존 조사 47개 항목 원문)를 열어.
4. 필요하면 오른쪽 상단 **PDF로 인쇄** 버튼을 사용해.

## 보고서 목차

- 출발점이 된 WMS 실무 경험과 연구 질문
- 홍익대 국방AI융합학과 교육영역, 과목 후보, 야간/주간 수업의 실제 차이
- 2026년 공식 학칙·안내를 기준으로 역산한 4학기 학점·시험·연구지도 계획
- 2027년 3월~2029년 2월 가상의 평일·학기 생활 시나리오
- 에이전틱 RAG 보조연구의 최소구현 범위와 비교실험·평가지표
- 모사 데이터, 군 보안, 군위탁 추천, 장학, 등록금 및 도입 허가
- 성공하지 못할 경우의 대안과 면접 핵심 네 질문의 결과 정리
- 학교 공식 출처, 학술 근거, 제출원문 보존 부록

## 근거와 미확정 구분

- **P01 / P47:** 사용자가 직접 제공한 수학계획서와 과거 조사 기록. 역사적 상태를 현재 제도로 단정하지 않아.
- **S01~S07:** 홍익대 모집공고·학사 안내·학과 소개 등 공개 근거.
- **R01~R04:** RAG, 생성형 AI 안전 및 평가 관련 참고 연구.
- **2027년 실제 수업표, 연구지도 교수, 학위청구 방법과 장학금 연속 적용은 미확정**이므로 학교 확인이 필요해.

## 보안과 배포

저장소는 **Private**를 유지해. 문서에는 개인의 진학동기와 군 업무 관련 서술이 포함돼 있어. 공개 GitHub Pages로 배포하면 저장소가 비공개여도 사이트가 공개될 수 있으므로 별도 보안 검토 전에는 활성화하지 않는 게 좋아. 업무 코드·로그·IP·품목 정보 등의 원본 추가는 하지 말아야 해.
