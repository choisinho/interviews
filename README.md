# 국방 AI · 면접 아틀리에

홍익대학교 일반대학원 세종캠퍼스 **국방AI융합학과 2027학년도 전기 석사 면접**을 준비하기 위한 개인용 정적 웹앱.

## 실행하기
이 저장소의 `index.html`을 다운로드한 뒤 Chrome/Whale 등의 브라우저에서 열면 돼. **HTML 한 파일에 스타일, 데이터, JavaScript가 모두 들어 있어** 인터넷이나 별도 서버 없이도 실행돼.

## 들어 있는 자료
- 면접 핵심 질문 네 가지: 자기소개 및 지원동기, 입학 후 계획, 졸업 후 포부, 야간수업 가능 여부
- 기본·확장 구술 답변과 말하기 연습 타이머
- 예상 꼬리질문 25개, 무작위 질문, 검색, 학습 완료 표시
- 실제 WMS 유지보수 경험을 활용한 사례·연구 목표 설명
- 2027~2029년 4학기별 학업/연구 시나리오와 주간 시간 활용 계획
- 에이전틱 RAG 진단보조 연구설계, 실험 비교조건, 평가 지표, 보안 고려사항
- 대학원 모집·학사·강의 형태·장학·취학추천 관련 사실 확인 및 미확정 사항 구분
- **제출 수학계획서 전문과 기존 홍익대 조사 47개 항목 전문** (웹앱 '원문·조사 기록' 화면)

## 주의할 점
- 지금 저장소는 개인 학습용 **비공개 저장소**다. 실제 군 자료, 내부 코드/로그, 서버 IP, 인증정보, 부대·품목 식별값을 추가하거나 무단 공개하지 마.
- GitHub Pages를 켜면 저장소가 비공개여도 공개 웹사이트가 될 수 있어. 사용 권한/공개 범위를 반드시 확인해야 해.
- 학과의 2027년 과목 실제 개설·수업시간·온오프라인 방식은 확정되지 않았다. 웹앱에서 '확인 / 이전 기록 / 미확정'을 구별해 읽어야 해.
- 학습 체크 상태는 브라우저의 `localStorage`에 저장되며 GitHub와 동기화되지 않는다.
