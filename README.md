# 국방 AI · 면접 아틀리에

홍익대학교 일반대학원 세종캠퍼스 **국방AI융합학과 2027학년도 전기 석사 대면 구술면접**을 준비하는 개인용 학습 웹앱. 2026-11-01 심층조사 및 팩트체크 결과를 기존 아틀리에의 연습 경험에 재통합했다.

## 실행 방법

저장소 루트의 `index.html`을 내려받아 Chrome/Whale 등의 브라우저에서 더블클릭해서 열면 돼. **CSS·JavaScript·학습자료가 모두 HTML 한 파일 안에 있으므로 오프라인 실행이 가능해.** 브라우저에서 실시간으로 여는 GitHub Pages는 기본적으로 활성화하지 않았다.

## 학습 루트

1. **홈** — 지원 동기 → 학업 계획 → 졸업 후 포부를 연결하는 한 줄 이야기.
2. **핵심 4문항** — 자기소개/학과지원동기, 입학 후 계획, 졸업 후 포부, 야간수업 가능 여부의 **30초·60초·90초+ 답변**, 타이머, 가리기, 복사, 연습 완료 체크.
3. **꼬리질문 44개** — 기술, 연구·실험, 입학·학사, 군 보안, 생활 병행, 비판적 질문. 검색·주제별 필터·무작위 질문.
4. **실전 모의면접** — 무작위 출제, 답변 숨김, 말하기 타이머, 자신감 1~5 기록, **1·2점 약점만 재출제**.
5. **면접 직전 한 장** — 30초 핵심 네 문항, 말하지 않아야 할 과장 표현, 현장 준비 체크리스트.
6. **실무 경험** — 바코드/ZPL, 화면·DB 수정, 레거시 장애 사례를 연구문제로 바꾸는 흐름.
7. **2년 대학원 시뮬레이션** — 2027~2029년 4학기 학점·수업·연구 마일스톤과 현실적 대안.
8. **연구 설계 실험실** — 읽기 전용 RAG 기반 WMS 원인탐색 지원, 비교조건과 평가지표, 위험 한계.
9. **현실성 조사 결과** — 사용자가 직접 체크하는 화면이 아니라, 학교 공식자료와 이전 조사기록을 교차 확인한 **16개 조사 결론·근거 링크·현실적 영향**, **3가지 4학기 시나리오**, 공개 검색으로는 확인이 불가능한 5개 사항의 이유를 보여주는 조사 화면.
10. **팩트체크와 근거** — 핵심 주장 **19건**의 판정과 출처링크, 총 **22개** 출처·선행연구.
11. **심층 검증 자료실** — 기존 '지원서에서 실제 2년으로' 학업·연구 현실화 보고서 본문 통합.
12. **원문·조사 기록** — 지원자가 전달한 **수학계획서 1~4항 전문**, 이전 조사 **47개 항목 전문**을 변경 없이 보존.

## 중요한 구분

- **학교 공식자료:** 해당 연도와 범위에만 적용되는 공지·학칙·모집요강. 2026 수강 안내가 2027 실제 개설·출석을 보장하지 않아.
- **지원자 제공 자료:** 실무 경험, 당시 시간표 확인, 장학액·취학추천 진행의 과거 기록. 공식의 현재 확정 사실로 승격하지 않아.
- **연구 시나리오:** 2027~2029년 4학기 학점·근무·RAG 실험은 합격·등록·지도교수·보안승인을 전제로 한 계획.
- **미확정:** 2027 학과별 학위청구 허용 경로, 실제 강의요일·시간·온라인 여부, 군위탁 장학 계속요건, 개별 연구자료 사용 허가.

## 면접 핵심 원칙

> 노후 WMS 유지보수에서 신규 담당자의 원인탐색 진입장벽을 경험했다 → AI·데이터 분석과 군수 운영을 배운다 → 근거검색 기반 읽기 전용 RAG 도구가 탐색시간과 정확도에 도움이 되는지를 독립 모사자료로 검증한다 → 인수인계·장애대응 업무의 지속가능성을 높인다.

실제 군 정보체계 자동 수정, 미승인 군 자료 반출, 모든 과목이 야간 온라인이라는 보장, 2년 안 실운영 배포 같은 주장은 하지 않아.

## 보안 / 개인정보

**비공개 저장소 상태를 유지**하는 것을 권장해. 개인 진학 서술과 군 정보체계 관련 일반적 업무 경험이 포함돼 있다. **Private 저장소가 군 내부 정보의 승인된 보관처라는 뜻은 아니야.** 실운영 코드·실제 DB 구조·로그·망주소·부대 및 품목 식별정보를 추가하지 마. GitHub Pages를 켜면 사이트가 외부에 공개될 수 있으니 별도로 공개 적합성 검토가 필요해.

## 기술

바닐라 HTML/CSS/JavaScript, 외부 라이브러리·서버·광고·분석 스크립트 없음. 학습 완료/자신감 점수는 현재 브라우저의 `localStorage`에만 저장돼. 기기 간 동기화는 지원하지 않아.
