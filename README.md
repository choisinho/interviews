# 국방 AI · 면접 아틀리에

**홍익대학교 일반대학원 세종캠퍼스 국방AI융합학과 2027학년도 전기 면접 준비용 개인 웹앱.**

2026-11-01에 기존 **면접 아틀리에**의 인터페이스와 학습 흐름으로 복귀했어. 기존의 「지원서에서 실제 2년으로」 심층조사 본문도 삭제하지 않고 앱의 **심층조사 본문** 메뉴에 통합했어.

## 사용법

1. `index.html`을 다운로드해 크롬/웨일/사파리에서 열어. 외부 서버와 추가 파일 없이 작동해.
2. **핵심 4문항**에서 30초·60초·90초 답변을 연습해. 답변 가리기와 타이머를 활용하면 돼.
3. **꼬리질문 훈련**에서 35문항을 주제별로 찾아보고 학습 완료를 표시해.
4. **모의면접**에서 핵심/꼬리/전체 질문을 무작위로 받아 말해. 답변 확인 후 충분함·보완·다시 중 하나로 직접 평가해. 자동 녹음이나 AI 채점은 하지 않아.
5. **약점 복습**에서 보완·다시로 표시한 질문만 재연습해.
6. **면접 당일 한 장**에서 핵심 메시지와 보안·학사 미확정 주의사항을 확인하고 인쇄해.
7. **심층조사 본문**에서 12개 장의 2027~2029년 학업·연구·군 보안·학점·행정 현실성 검토를 읽어.
8. **팩트체크와 근거**에서 학교 공식자료 링크와 이전 기록/미확정 상태를 구별하고, **원문·조사 기록**에서 제출 수학계획서와 과거 조사 47개 항목의 원문을 열어.

검색(상단 돋보기 또는 `/`), 글자 크기 조절, 모바일 메뉴, 체크리스트·학습 진도 로컬 저장을 지원해. PC에서 복사/붙여넣기를 하지 않아도 메뉴와 버튼만으로 연습할 수 있게 구성했어.

## 근거 수준과 검증 대기

- **P01 / P47:** 지원자 제공 수학계획서와 과거 조사 47개 항목. 원문은 변경하지 않고 보존.
- **S:** 홍익대 공개 모집·학사·학과 자료. 확인한 시점과 해당 학년도 범위를 구별해야 함.
- **R:** RAG, AI 안전, 평가방법 관련 참고자료.
- **계획/가정:** 2027~2029년 학기별 과목·학점·시간표·연구 진행 시나리오. 실제 개설·학과 허용 여부가 확정된 것은 아님.

**중요:** 이 브랜치는 **기존 자료의 사전 통합판**이야. 별도로 진행 중인 심층 팩트체크 최종 결과는 아직 반영되지 않았어. 2027 실제 수업 방식, 학위청구 경로, 군 취학추천 승인·전형 반영, 장학금 재추천 요건, 지도교수 배정, 연구자료 보안승인은 확정적으로 서술하면 안 돼. 기존 보고서의 출처와 날짜도 최종 조사 결과가 나오면 다시 대조할 예정이야.
